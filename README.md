### 分支（Branch）
分支就像在一本书的主线剧情之外，另起一页写一个番外篇。你可以在番外篇里自由修改内容，而主线剧情（主分支 main）不受影响。这样多人协作或尝试新功能时，不会破坏稳定版本。

### 合并（Merge）
合并就是把番外篇的内容整合回主线剧情中。当你确认番外篇的修改没有问题后，通过 `git merge` 操作将分支的更改合并到主分支，让两部分内容合二为一。
## 1.能自己玩的贪吃蛇

### 实现方式
我采用纯前端单文件（HTML/CSS/JS）的方式，用Canvas绘制游戏区域。
- 蛇用数组存储坐标，每150ms移动一步
- 键盘方向键控制方向，通过检查当前方向防止180°掉头
- 食物随机生成在空白格子上
- 撞墙或撞自身触发游戏结束

### 代码逻辑
1. **蛇的移动与变长**：蛇的身体是一个数组，第0个元素是蛇头，最后一个元素是蛇尾。每次移动时，我计算新蛇头的位置并插入到数组最前面，然后根据是否吃到食物来决定是否移除蛇尾。如果吃到了食物，蛇尾保留（长度+1）；如果没吃到，移除蛇尾（长度不变）。方向用 x 和 y 的偏移量表示，比如 {x:1, y:0} 表示向右移动一格。
2. **方向控制**：方向控制的关键是防止蛇180°掉头撞到自己。例如蛇当前正在向上移动（dy = -1），如果玩家按下"下"键，蛇会立刻掉头向下，导致蛇头撞到自己的身体。解决方案是：在改变方向前检查当前移动方向，只有新方向与当前方向相反时才忽略此次按键。代码中用 dy !== 1 判断"当前不是向下"，以此允许向上移动。
3. **碰撞检测**：游戏结束分两种情况：一是蛇头超出画布边界（撞墙）；二是蛇头与自己的身体（从第2节开始检查）坐标重叠（撞自身）。注意检查自身时要跳过蛇头本身（索引0），否则会误判为"蛇头撞到自己"导致游戏立即结束。

## 3.RC电路
### 理论计算
传递函数：H(jω) = 1/(1+jωRC)
截止频率：fc = 1/(2πRC) = 1/(2π×1000×100×10⁻⁹) ≈ 1591.55 Hz
### 仿真验证
使用 PySpice 进行 AC 扫频分析（1Hz~1MHz），代码见pyspice.py

 项目            理论值       仿真值       误差    
 截止频率 fc   1591.55 Hz    ≈1585 Hz     <0.5%

结论：仿真值与理论值高度吻合，误差主要来自扫频的离散化（频点不是连续无限密）
• 低频段（<100Hz）：增益接近 0dB（即 |H|≈1），信号几乎无衰减通过
• 截止频率附近（≈1591Hz）：增益为 -3dB，曲线开始明显下降
• 高频段（>10kHz）：增益以 -20dB/十倍频程 的斜率下降
这个 -20dB/dec 的斜率是一阶滤波器的典型特征。
## 4.电路：验证戴维南定理

### 电路设计
- 原始电路：Vin=10V, R1=10kΩ, R2=10kΩ, R3=10kΩ
- 输出端：R2 右侧与地之间

### 理论计算

#### 求 V_th（开路电压）
R2 右侧开路 → R2 无电流 → Vout = V_A
V_A = Vin × R3/(R1+R3) = 10 × 10/20 = 5V
**V_th = 5V**

#### 求 R_th（等效电阻）
将 Vin 短路，从输出端看进去：
R1 与 R3 并联 = 5kΩ
再与 R2 串联 = 10 + 5 = 15kΩ
**R_th = 15kΩ**

#### 接 10kΩ 负载后的理论输出
Vout = V_th × RL/(R_th+RL) = 5 × 10/25 = 2V

### 仿真验证
完整代码见['dwn.py'](./dwn.py)
